# QR Code Generator

A simple and responsive QR Code Generator built using HTML, CSS, and JavaScript. It allows users to generate QR codes from text or website URLs and download them as PNG images.

## 🚀 Features

- Generate QR codes from text.
- Generate QR codes from website URLs.
- Preview generated QR codes.
- Download QR codes as PNG images.
- Simple and user-friendly interface.
- Responsive design for mobile and desktop.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- QRCode.js Library

## 📁 Project Structure

```text
QR-Code-Generator/

```

## 💻 How to Run

1. Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/QR-Code-Generator.git
```

2. Open the project folder in VS Code.

3. Install the Live Server extension.

4. Right-click `index.html`.

5. Select **Open with Live Server**.

6. Enter text or a URL and click **Generate QR Code**.

7. Click **Download QR Code** to save your image.

## 📸 Usage

1. Enter your text or website URL.
2. Click the Generate QR Code button.
3. View your generated QR code.
4. Download it as a PNG image.
